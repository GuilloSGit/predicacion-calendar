# Política de privacidad — Predicación Calendar

Última actualización: 2026-09-21

Predicación Calendar es una herramienta personal que se ejecuta localmente en la computadora del usuario. No tiene servidores propios.

## Datos a los que accede

- **Google Calendar:** con autorización del usuario (permiso `calendar`), crea, modifica y elimina únicamente los eventos que ella misma generó en un calendario llamado "Predicacion".
- **Imagen del cuadro de salidas:** si el usuario la carga, se envía a la API de Gemini de Google para transcribirla a texto.

## Almacenamiento y uso

- Las credenciales de acceso (`token.json`) se guardan solo en la computadora del usuario.
- No se recopila, almacena en servidores, vende ni comparte ningún dato con terceros.
- Los datos se usan únicamente para crear los eventos del calendario.

## Revocar el acceso

Se puede revocar en cualquier momento desde https://myaccount.google.com/permissions y borrando el archivo `token.json`.
